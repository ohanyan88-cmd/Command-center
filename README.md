## Ինչպես ենք աշխատում (պարզ)

- **Ամեն ինչ, ինչ ձեռքդ ընկնում է** → գցի `00_ԳՑԻՐ_ԱՅՍՏԵՂ/`։ Ես տանում եմ ճիշտ տեղը, վերանվանում, գրանցում։
- **Դու** աշխատում ես `Առաջադրանքներ.xlsx`-ում՝ փոխում ես կարգավիճակներ, գրում մեկնաբանություններ։
- **Սկրիպտ, .bat, ոչ մի բան չես գործարկում** — երբ պետք լինի մի բան վերակառուցել (գրաֆիկ, նոր առաջադրանքներ, պատկեր), ուղղակի ասում ես ինձ, ես անում եմ։
- **Ես քո գործառնական օգնականն եմ** ամեն ինչի մասով, ոչ միայն WhatsApp-ի։ Դերս՝ [04_WhatsApp/ՕԳՆԱԿԱՆ_դերը.md](04_WhatsApp/ՕԳՆԱԿԱՆ_դերը.md)։
